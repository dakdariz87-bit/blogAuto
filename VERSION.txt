v0.1.4: 실제 다운로드 MB·진행률과 압축 해제 단계를 표시. 서버 무응답 제한 시간 추가. GitHub 연결 실패 시 동일 원본 체크섬을 검증하는 npm 미러로 전환. 설치 전체 12분 제한.
v0.1.3: Electron 설치 스크립트의 종료 코드에 의존하지 않고 원본에 고정된 Windows 배포 파일을 직접 다운로드·체크섬 검증·압축 해제. 실행 파일 형식·버전·경로까지 확인. electron-setup.cjs 파일 추가.
v0.1.2: Windows Path/PATH 혼용으로 node 경로가 사라지던 문제 수정. Codex 로그인을 node.exe로 직접 실행. npm이 생략한 Electron 설치 스크립트는 해당 패키지만 확인 후 실행.
v0.1.1: npm 설치 경로의 따옴표가 폴더 이름에 포함되던 오류 수정.
