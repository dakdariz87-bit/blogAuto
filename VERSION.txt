v0.2.2: 기관 main 본문 전체 추출. 수집 12000자·조사 전달 6000자로 확대하여 주의사항 누락 완화. 근거 있는 핵심 주제로 범위를 조정하고 불필요한 의료 권고 요구 제거.
v0.2.1: AI 최종 응답을 앱이 직접 저장. 최신 agent_message.text 이벤트 지원. 작업 폴더 workspace-write 명시. 결과 누락 시 무조건 재호출하지 않고 오류 표시. 단계 기준 진행률과 중단 원인 표시.
v0.2.0: 앱 안에서 ChatGPT OAuth 연결·상태 확인·취소. 실제 Codex 모델 목록 조회와 Astra·6.x 선택/저장 지원. 블로그 주소로 네이버 연결. 첫 초안 설정과 앱 내 사용법 추가. 로그인만으로 자동 작업을 시작하지 않음. 실행 전 터미널 로그인 제거.
v0.1.6: 압축 해제 시 파일 개수 대신 디스크 기록 완료 바이트를 감지. 큰 electron.exe 하나를 푸는 동안에도 진행 표시·감시. 압축 해제 무진행 120초·전체 10분으로 분리. Windows에서 검증한 Electron 포함 묶음 추가.
v0.1.5: 설치 작업을 별도 프로세스로 분리. 실제 바이트/파일 증가가 30초 멈추면 외부 감시자가 강제 종료 후 대체 서버로 전환. npm ci의 자동 설치 스크립트 생략. 설치 단계와 실제 진행량 표시. Windows 실행 검증 워크플로 추가.
v0.1.4: 실제 다운로드 MB·진행률과 압축 해제 단계를 표시. 서버 무응답 제한 시간 추가. GitHub 연결 실패 시 동일 원본 체크섬을 검증하는 npm 미러로 전환. 설치 전체 12분 제한.
v0.1.3: Electron 설치 스크립트의 종료 코드에 의존하지 않고 원본에 고정된 Windows 배포 파일을 직접 다운로드·체크섬 검증·압축 해제. 실행 파일 형식·버전·경로까지 확인. electron-setup.cjs 파일 추가.
v0.1.2: Windows Path/PATH 혼용으로 node 경로가 사라지던 문제 수정. Codex 로그인을 node.exe로 직접 실행. npm이 생략한 Electron 설치 스크립트는 해당 패키지만 확인 후 실행.
