BlogAuto 사용법

처음에는 초안을 한 편 만들어 내용을 확인하세요. 로그인만으로 글 생성이나 발행을 시작하지 않습니다.

  1. ChatGPT 연결

    앱 상단의 ChatGPT 연결 → 열린 공식 로그인 화면에서 로그인 → 앱으로 돌아와 연결 상태 확인. 이미 Codex에 로그인돼 있으면 기존 연결을 사용합니다. 비밀번호나 인증번호는 앱에 입력하지 않습니다.

  2. 모델 선택

    모델 새로고침 → 상단 글 작성 모델에서 선택. Astra를 포함해 계정의 Codex 모델 목록에 있는 모델을 사용할 수 있습니다. ‘계정에서 미확인’ 모델은 선택할 수 없습니다. 낮음/높음은 각 작업의 추론 강도이며 별도의 모델 이름이 아닙니다.

  3. 네이버 연결

    블로그 주소 또는 ID 입력 → 네이버 연결 → 프로그램이 연 Chrome에서 직접 로그인. dakdariz 블로그라면 https://blog.naver.com/dakdariz 를 입력합니다. 다른 계정의 블로그는 등록하지 마세요. 연결 완료 여부는 앱의 상태 표시로 확인합니다.

  4. 카테고리와 검색 키워드 등록

    첫 글 작성 설정하기 → 카테고리 관리에서 카테고리 명(예: 자세관리), 검색 키워드(예: 앉은 자세 목 어깨)를 입력 → 카테고리 등록/수정. 이 카테고리는 프로그램의 주제 분류용입니다. 원하는 카테고리의 체크를 켜세요.

  5. 주제와 이미지 설정

    글 발행 방식은 ‘주제 직접 입력 · 초안 1개’, 주제는 ‘오래 앉아 있을 때 목과 어깨가 뻐근한 이유’처럼 구체적으로 입력합니다. 이미지 옵션과 문장 줄바꿈을 확인하세요. 이미지 스타일 참고 사진은 계정 관리에서 등록할 수 있습니다.

  6. 초안 생성

    ‘생성 후 Naver 발행까지 진행’을 끈 상태에서 작업 시작 → 생성된 본문과 이미지 확인. 초안 생성만으로 네이버에 게시되지는 않습니다. ChatGPT/Codex 계정의 사용량 한도가 적용됩니다.

  7. 발행과 자동 반복

    발행까지 켜고 작업 시작하면 글 생성에 이어 네이버 발행을 진행합니다. 전체공개/비공개와 예약 시간을 먼저 확인하세요. ‘자동 주제 선정 · 반복 발행’은 체크한 계정·카테고리로 주기마다 발행하는 모드입니다. 초안 확인 단계가 필요하면 첫 글 설정과 수동 방식을 사용하세요. 자동 중지는 다음 반복을 중지하며 이미 진행 중인 발행을 취소하지는 못할 수 있습니다.

연결이 안 되거나 모델이 보이지 않을 때

ChatGPT: 연결 상태 확인 → 필요하면 ChatGPT 연결을 다시 진행하세요. 네이버: 앱이 연 Chrome에서 로그인하고 팝업·복구 안내를 닫으세요. Astra가 목록에 없다면 현재 Codex 계정에서 확인되지 않은 상태입니다. 이 앱에서 사용 권한을 추가할 수는 없습니다. 모델 새로고침 또는 계정 기본 모델을 선택하세요.
계정별 로그인이 필요합니다.

  • 3. 첫 글 작성 설정하기를 누르세요. 사용법 보기는 언제든 다시 열 수 있습니다.
