# 블로그 작성 도우미 0.5.0

## 설치

최신 ZIP을 새 폴더에 풀고 chrome://extensions 에서 기존 확장 프로그램을 제거한 뒤 새 chrome-extension 폴더를 로드합니다. 별도의 Node.js 실행은 필요 없습니다. Chrome이 사진 붙여넣기를 위한 클립보드 쓰기 권한을 추가로 안내할 수 있습니다. 네이버 전체 사이트에 대한 상시 접근 권한은 추가하지 않았습니다.

## 초안 전체 확인

큰 창으로 열기를 누르세요. 현재 본문 글자 수와 원본 글자 수, 줄 수, 마지막 부분이 본문 위에 표시됩니다. 원본 파일에는 참고자료까지 들어 있습니다. 저장된 편집본이 짧다면 원본 다시 불러오기로 원본 전체를 복원합니다. 덮어쓰기 전 확인을 받고 이전 편집본은 로컬에 보관합니다.

제목·본문 전체 복사는 스크롤 위치와 관계없이 전체 문자열을 복사합니다. 복사할 때 선택한 사진은 텍스트에 포함되지 않습니다. 실제 사진은 입력 버튼을 통해 별도로 붙여넣습니다.

## 서식

소제목 자동 굵게, 본문·소제목 크기, 소제목 색을 선택할 수 있습니다. 본문에서 문구를 선택한 뒤 굵게·기울임·밑줄·배경 강조 버튼을 누르세요. 직접 **굵게**, *기울임*, __밑줄__, ==배경 강조==를 입력할 수도 있습니다. ## 로 시작하는 짧은 문단은 소제목으로 처리합니다.

미리보기는 원하는 배치입니다. 네이버에는 실제 키 입력과 확인 가능한 도구 모음 버튼으로 적용합니다. 크기·색·배경 메뉴를 확인하지 못하면 결과에 경고를 남깁니다. 네이버 전용 인용구·모든 스티커·모든 글자 효과를 완전히 재현하는 기능은 아닙니다.

## 사진

이미지 위치를 체크하고 PNG·JPG·WebP 파일을 선택합니다. 선택한 사진은 최대 1400px 범위에서 PNG로 변환하고 크기에 따라 더 줄일 수 있습니다. 미리보기와 파일명을 확인하세요. 선택 사진은 크롬 세션 저장소에 임시 보관하며 외부 서버로 전송하지 않습니다.

입력을 승인하면 클립보드에 선택한 사진을 쓰고 네이버에 붙여넣습니다. 기존 PC 클립보드 내용이 선택 사진으로 바뀝니다. 네이버에서 이미지 요소와 로딩 여부를 확인합니다. 업로드를 확인하지 못하면 위치에 【사진 확인 필요: 파일명】 표시를 남기고 본문 입력을 계속합니다. 사진을 선택하지 않은 위치는 【이미지 삽입 위치】 안내가 들어갑니다.

사진 업로드는 실제 네이버에서 검증이 필요합니다. 실패한 표시를 실제 사진으로 바꾸고 안내 문구를 지운 뒤 발행하세요. 이미 들어간 사진은 중복 업로드하지 않도록 직접 확인합니다.

## 스티커

입력 후 네이버 스티커 패널 열기를 체크하면 본문 입력 후 스티커 버튼을 누릅니다. 원하는 스티커는 사용자가 패널에서 직접 선택합니다. 유료·보유 여부가 다른 스티커를 임의 구매하거나 자동 선택하지 않습니다. 버튼을 찾지 못하면 직접 클릭하도록 안내합니다.

## 입력과 결과

네이버 글쓰기 열기 / 돌아가기 버튼으로 dakdariz 새 글을 열고, 새 탭인 경우 그 탭에서 확장 프로그램을 다시 열어 입력 권한을 부여하세요. 빈 새 글에서만 입력합니다. 기존 내용은 덮어쓰지 않습니다. 입력 중 마우스·키보드를 조작하지 마세요.

마지막에 네이버의 전체 텍스트와 준비한 본문을 비교합니다. 이미지가 들어간 뒤 텍스트가 여러 영역으로 나뉘어도 전체를 읽습니다. 제목·본문 확인 성공과 사진·서식 적용 성공은 구분합니다. 실패한 효과가 있으면 결과 안내와 실제 네이버 화면을 확인하세요. 자동 발행은 하지 않습니다.

현재 크롬 로그인 상태를 사용하며 비밀번호·쿠키는 읽지 않습니다. 디버깅 연결은 작업 중에만 유지합니다. 모의 편집기의 긴 원본 복원, 전체 복사, 굵게·문단 키 입력, 사진 파일 선택·전달 등 8개 테스트가 통과했습니다. 실제 네이버의 색상·크기·스티커 메뉴와 사진 업로드 결과는 사용자 PC에서 확인해야 합니다.
