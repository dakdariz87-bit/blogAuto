# 기존 크롬 로그인으로 초안 입력

Node.js와 start-windows.bat를 실행할 필요가 없는 크롬 확장 프로그램입니다. 로그인된 기존 크롬에서 실행하므로 별도 로그인 프로필을 만들지 않습니다. 네이버가 로그아웃하거나 추가 인증을 요구하면 직접 처리해야 합니다.

1. 저장소의 Code → Download ZIP으로 최신 파일을 다운로드하고 새 폴더에 모두 압축 해제합니다.
2. 평소 사용하는 크롬 주소창에 chrome://extensions 를 입력합니다.
3. 오른쪽 위 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다.
5. blogAuto-main 안의 chrome-extension 폴더를 선택합니다. manifest.json이 들어 있는 폴더입니다.
6. 네이버에서 dakdariz 계정으로 로그인하고 https://blog.naver.com/PostWriteForm.naver?blogId=dakdariz 를 엽니다.
7. 로딩을 기다리고 도움말·복구 창이 있다면 닫습니다. 제목과 본문이 비어 있는 새 글에서만 실행합니다.
8. 크롬 오른쪽 위 퍼즐 모양 → 블로그 초안 입력 테스트를 누릅니다.
9. 초안을 확인하고 승인 체크 → 제목·본문 입력하기를 누릅니다.
10. 실제 제목·본문과 줄바꿈을 확인하고 네이버 사진 버튼으로 이미지를 첨부한 뒤 직접 발행합니다.

이 버전은 기존 크롬 로그인 상태로 제목·본문 입력을 시험합니다. AI 글 생성, 사진 자동 첨부, 자동 발행은 아직 제공하지 않습니다. 실제 네이버 편집기에서의 동작은 사용자 PC에서 검증이 필요합니다. 입력 실패 시 발행하지 말고 화면을 확인해주세요. 일부만 들어갔을 때 반복 입력하면 덮어쓰기를 거부합니다.

확장 프로그램은 버튼을 누른 현재 탭에만 접근하고 로그인 비밀번호·쿠키를 읽거나 별도 서버로 전송하지 않습니다. 초안은 패키지의 draft.json에 있습니다. 설치 후 삭제는 chrome://extensions 에서 제거를 누릅니다.
