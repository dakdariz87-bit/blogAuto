# 블로그 작성 도우미 0.4.0

평소 사용하는 크롬에서 로그인한 dakdariz의 빈 새 글에 초안을 입력합니다.

## 설치와 업데이트

최신 ZIP을 새 폴더에 압축 해제하고 chrome://extensions 에서 기존 확장 프로그램을 제거한 뒤 새 chrome-extension 폴더를 로드합니다. 팝업 상단의 버전 0.4.0을 확인하세요. Node.js나 start-windows.bat는 사용하지 않습니다.

## 큰 창

네이버의 빈 글쓰기 탭에서 확장 프로그램을 열고 큰 창으로 열기를 누릅니다. 별도 창 왼쪽에서 제목·본문을 수정하고 오른쪽에서 배치를 확인할 수 있습니다. 처음 선택한 네이버 탭을 입력 대상으로 유지하므로 그 탭을 닫지 마세요. 초안과 설정은 크롬 로컬 저장소에 탭별로 저장됩니다.

## 줄바꿈과 정렬

본문 각 줄 사이에 실제 Enter 키를 보내 빈 줄과 문단 간격을 유지합니다. 기본은 가운데 정렬이며 왼쪽 정렬로 바꿀 수 있습니다. 정렬 단축키 또는 확인 가능한 정렬 버튼을 사용하고 실제 적용 여부를 확인합니다. 확인하지 못하면 결과에 수동 확인 안내를 표시합니다.

미리보기는 배치 참고용입니다. 기존 블로그의 글꼴·색 강조·인용구 전체를 복제하지는 않습니다.

## 이미지 위치

추천 위치 중 필요한 항목을 체크하고 이미지 설명을 수정합니다. 본문을 크게 바꾸면 이미지 위치 다시 추천을 누르세요. 선택한 위치에는 【이미지 1 삽입 위치: 설명】 같은 안내 문구가 들어갑니다.

실제 사진 파일은 자동 업로드하지 않습니다. 네이버 사진 버튼으로 해당 위치에 사진을 첨부한 뒤 안내 문구를 지워주세요. 발행 전에 남은 【이미지 …】 표시가 없는지 확인하세요.

## 입력과 검토

승인 체크 후 입력 버튼을 누르면 네이버 창으로 전환해 처리합니다. 입력 중 브라우저·마우스·키보드를 조작하지 마세요. 완료 후 큰 창에서 결과를 확인하세요.

앞서 시험 입력한 내용이 있으면 덮어쓰지 않습니다. 새 빈 글에서 실행하세요. 결과를 네이버에서 확인하고 사진을 첨부한 후 직접 발행합니다. 자동 발행은 포함되지 않습니다.

Chrome 디버깅 권한은 입력할 때 연결하고 종료 후 해제합니다. 비밀번호·쿠키를 읽거나 외부 서버로 전송하지 않습니다. 실제 네이버에서 정렬과 줄바꿈 적용 여부는 확인이 필요합니다. 모의 편집기에서는 줄바꿈 전송, 이미지 위치 선택과 미리보기, 큰 창의 원래 탭 연결을 테스트했습니다.
