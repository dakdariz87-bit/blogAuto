# 네이버 블로그 자동화 — dakdariz 검토 버전

주제·본문·이미지를 만든 뒤 사용자가 검토하고 승인해야 네이버로 전송하는 Windows 데스크톱 앱입니다. 이전에 만든 단독 확장 프로그램과는 별도의 앱·동반 확장입니다.

## 처음 실행

1. 저장소 ZIP을 다운로드하고 전체 압축을 풉니다.
2. Node.js **24 이상**과 Google Chrome이 필요합니다.
3. Codex CLI가 없다면 `setup-codex.cmd`를 실행해 설치·로그인합니다. 이미 설치했다면 본인 Codex 로그인 상태를 확인하세요. 비밀번호·API 키·토큰을 GitHub나 대화에 보내지 마세요.
4. **이 폴더의 `start-windows.cmd`**를 실행합니다. 이전의 루트 `start-windows.bat`는 사용하지 않습니다. 첫 실행에는 앱 패키지와 Electron 다운로드가 있어 수 분 걸릴 수 있습니다.
5. 앱의 `dakdariz 테스트` 계정과 카테고리를 확인합니다. 기본 카테고리 `운동학·몸교정`은 설정 예시이므로 **실제 네이버 카테고리명**으로 수정하세요.
6. 앱의 **블로그 열기 / 로그인**으로 기존 Chrome을 열고 현재 네이버 계정이 dakdariz인지 확인합니다.
7. 앱의 **크롬 확장 설치 → 설치 폴더 준비**를 누릅니다. Chrome의 `chrome://extensions`에서 개발자 모드 → 압축해제된 확장 프로그램 로드 → 앱이 준비한 폴더를 선택합니다. 이전 단독 `블로그 초안 입력 테스트` 확장과 혼동하지 마세요.
8. 앱의 **확장프로그램 연결**에서 받은 코드를 동반 확장에 입력합니다. 연결할 때 Chrome이 네이버 사이트 접근 권한을 묻습니다. 허용해야 이 사이트의 자동 입력이 가능합니다.

## 사용 순서

**주제 선정·초안 만들기 → 전체 원고·그림 검토/수정 → 공개설정 확인 → 검토한 원고 승인 후 네이버로 보내기**

- 처음에는 공개설정 **임시저장**으로 테스트하세요. 공개 게시를 원하면 승인 전에 **전체공개**를 선택합니다. 승인한 공개설정에 따라 네이버에 실제 저장·발행합니다.
- 생성이 끝나면 자동 반복을 멈추고 검토를 기다립니다. 본문 전체 글자 수·끝부분을 표시하며 전체 복사도 가능합니다.
- 본문은 수정할 수 있습니다. 제목·본문·대상·그림 파일이 바뀌면 이전 승인은 재사용되지 않습니다.
- 제목/소제목은 네이버 인용구 스타일로, `[IMAGE INSERT - n]`은 해당 생성 이미지로 변환합니다. 원고와 실제 편집기 요소를 단계별로 대조하며 예상과 다르면 멈춥니다.
- 이미지 기본값은 본문 최대 **2장**, 선택 범위는 **0~4장**입니다. 타이틀 이미지 생성은 별도 옵션입니다.
- 네이버 보안 인증은 직접 처리해야 합니다. 인증을 자동으로 우회하지 않습니다.

## 로그인·비용·저장 위치

이 앱은 네이버 글쓰기 API를 사용하지 않습니다. 사용자의 Chrome 로그인과 Codex CLI를 이용합니다. 별도 OpenAI API 키를 새로 받도록 만들지 않았으며, **현재 PC의 Codex 인증 방식과 사용량 한도**가 적용됩니다. 소스 무료 공개가 AI 사용량 무제한을 의미하지는 않습니다. 이미지 생성 기능을 사용할 수 있는지도 본인 Codex 환경에서 확인해야 합니다.

설정·연결 정보·원고·이미지는 `%LOCALAPPDATA%\DakdarizBlogAuto`에 저장합니다. 업데이트 ZIP을 새 폴더에 풀어도 이 데이터를 유지합니다. 이 폴더에는 개인 작업 정보가 있으므로 GitHub에 올리지 마세요. 기존 Chrome의 쿠키 파일을 복사하거나 읽지 않습니다. Chrome 프로필이 여러 개면 열린 프로필과 네이버 계정을 직접 확인하세요.

확장은 로컬 브리지 `127.0.0.1:46321`과 연결합니다. 다른 BlogAuto 앱이 이 포트를 사용하면 종료 후 재실행하세요. 연결 코드는 만료되며, 이후에는 토큰으로 현재 계정의 작업을 확인합니다.

## 검증과 남은 제한

설치 패키지 고정 목록으로 `npm ci --ignore-scripts`를 확인했고, JavaScript 구문 검사 50개 파일과 7개 회귀 테스트가 통과했습니다. 실제 렌더러의 전체 복사·본문 수정·승인 버튼도 모의 연결로 확인했습니다. 실행용 의존성의 `npm audit --omit=dev`에서는 알려진 취약점이 보고되지 않았습니다.

**Windows/Electron의 실제 실행, 본인 Codex 계정의 생성·이미지 기능, 실제 네이버 임시저장·발행은 아직 이 환경에서 검증하지 못했습니다.** Windows 실행 파일(EXE)을 빌드한 결과물이 아니라 실행 가능한 소스와 실행 스크립트입니다. 스티커 자동 선택·구매는 포함하지 않습니다. 기존 블로그 전체의 말투 분석도 완료된 상태가 아닙니다. 기본 말투는 이전 대화에서 사용자가 수용한 샘플 방향을 설정했습니다.

검사 명령: `npm run check`, `npm test`. 실제 로그인·생성·발행은 이 검사에 포함되지 않습니다.
