분석일: 2026-11-08 (Asia/Seoul).

요청 저장소 `boksajang/blogauto-naver`의 확인 커밋은 `a98fb5ff0930b8abd6a4b6619b048dd8ba0e2565`입니다. README가 이 저장소를 구버전으로 표시하고 후속 `naverblog-extention`을 안내합니다. 후속판 `dc59b9e9c74c3aff063c921a03f2178a73c3d5d9`는 MIT 라이선스와 동반 확장을 제공하여 이를 `desktop/`에 기반 소스로 도입했습니다. 원저작권과 별도 제3자 고지를 그대로 보존했습니다.

유튜브 https://www.youtube.com/watch?v=9hAcDsqHlR4 는 공개 페이지 접근이 제한되어 영상 내용·자막을 직접 검증하지 못했습니다. 시연을 시청했다고 가정하지 않았습니다. 영상 제목의 검색 결과, 저장소 자체와 작성자의 프로젝트 설명 https://boksajang.com/projects/naverblog-extention/ 를 구분해서 참고했습니다. vidIQ 크레딧을 사용하는 유료 분석 호출은 하지 않았습니다.

## 확인한 문제와 변경

| 항목 | 원본 동작 | 이 배포판 |
|---|---|---|
| 사용자 검토 | 설정·작업 시작에서 자동 발행을 강제로 켜며 생성 뒤 이어서 발행 | 초안 저장 후 대기, 승인된 원고에만 게시 경로 허용 |
| 승인 범위 | 사용자 검토 단계가 없음 | 대상·공개설정·본문·실제 이미지 해시까지 묶어 승인, 변경 시 무효 |
| 이미지 수 | 양수는 모두 10장으로 정규화 | 기본 2장, 0~4장 선택값 유지 |
| Chrome | 네이버 계정별 별도 user-data-dir | 기존 Chrome 프로필 사용, 선택적으로 분리 가능 |
| 기존 작성 탭 | 새 작업 준비 시 기존 편집기를 새로 탐색할 수 있음 | 새 작업은 별도 글쓰기 탭 생성, 기존 미완성 탭 보존 |
| 원고 대기 | 생성만 실행한 분기에서 재사용 가능한 게시 초안 저장이 부족 | 원고·그림을 보존하고 승인 후 생성 없이 전송 |
| 전체 글 | `.value`로 전체 본문을 쓰며 원본은 잘라내지 않음 | 전체 분량·끝부분 표시, 본문 수정 및 Electron 클립보드 전체 복사 추가 |
| 사이트 권한 | Naver·로그인·Tistory에 설치 즉시 접근 | 루프백 연결 필수 + 네이버는 연결 버튼에서 사용자에게 선택 권한 요청; Tistory 권한 미요청 |
| 게시 반복 | 설정한 간격으로 다음 대상으로 진행 | 한 초안 생성 후 검토를 기다림 |
| 데이터 위치 | 개발 ZIP 위치에 runtime 저장 | Windows 앱 데이터 고정 폴더, 업데이트 때 유지 |

후속판의 유용한 부분도 유지했습니다. 네이버가 별도 입력 iframe을 사용하는 상황을 처리하고, 제목·문단·인용구·이미지를 한 단계씩 입력한 뒤 원고와 비교합니다. 일부만 입력된 상황에서 무작정 다시 붙이지 않으며, 게시 결과가 불확실하면 자동으로 같은 글을 재발행하지 않습니다. 로컬 브리지는 루프백에만 바인딩하고 Host·Origin·인증 토큰을 확인합니다. 이것은 전체 보안감사를 완료했다는 의미는 아닙니다.

## 확인 범위

- 패키지 설치: 고정된 lockfile로 실행용 패키지 설치 확인. Electron 바이너리 설치 스크립트는 이 검증에서는 실행하지 않음.
- 구문: 50개 JS/CJS 파일 통과.
- 회귀: 승인 전 차단, 대상/본문/사진 변경 시 승인 무효화, 이미지 수, 기존 Chrome 사용, 전체 본문·인용구/그림 순서, 부분 입력 중지, 브리지 거절 조건 등 7개 테스트 통과.
- UI: Chrome의 모의 preload 연결에서 편집 가능한 전체 본문, 마지막 문단 복사, 승인 대상 dakdariz 확인. Electron main process와 실제 게시의 종단 테스트는 아님.
- 의존성: 실행용 패키지 `npm audit --omit=dev` 결과 0건. 개발·빌드 도구 전체를 무취약하다고 판단한 것은 아님.
- 실시하지 않은 작업: AI 유료 요청, 네이버 로그인, 실제 발행, Windows EXE 빌드.

## 사용 시 확인할 점

Node.js 24 이상·Chrome·Codex CLI 로그인이 필요합니다. 기존 ChatGPT 브라우저 로그인과 Codex CLI 로그인은 같다고 가정하지 않습니다. 소스가 무료여도 Codex 플랜·계정의 사용 한도와 이미지 도구 가용성은 별개입니다. 검색 사이트 제한이나 네이버 편집기 변경에 따라 동작이 달라질 수 있습니다.

첫 실행은 실제 카테고리명을 맞춘 뒤 임시저장으로 검증하세요. 본문과 그림을 검토한 후 승인 버튼을 누르며, 공개 게시에는 공개설정을 별도로 선택합니다. 기존 블로그 글의 실제 말투를 세밀하게 반영하려면 대표 글 자료를 별도로 제공해야 합니다.
